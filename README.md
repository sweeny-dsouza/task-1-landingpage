# CyberShield — Responsive Cybersecurity Landing Page

CyberShield is a modern and responsive cybersecurity landing page designed and developed using HTML5 and CSS3.
The project focuses on clean UI design, responsive layouts, Flexbox positioning, and modern landing page structure.

##  Project Highlights

* Responsive navigation bar
* Modern hero section with call-to-action buttons
* Feature showcase cards
* Statistics section
* Call-to-action section
* Professional footer with contact information
* Responsive design using media queries
* Clean futuristic cybersecurity theme

##  Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries
* Google Fonts

##  Tools Used

* Visual Studio Code
* Live Server Extension
* Chrome Browser

##  Responsiveness

The landing page is fully responsive and adapts across:

* Desktop
* Tablet
* Mobile devices
